# Branding for the neslp league

A league's branding for the pinball league server: the home page and other
content pages, the email texts, icons and styles, and the names and menus in
`league.json`. The server reads it from a checkout of this repository
(`BRANDING_FOLDER`) and, when `BRANDING_URL` points at the raw files of this
repository, refreshes the pages in `pages/` while it runs.

See `docs/branding.md` in the server repository for the layout and each field.
